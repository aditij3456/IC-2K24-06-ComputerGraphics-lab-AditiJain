# CGM Lab Assignment 1: Basic Shapes

## Description

This C++ program uses the `graphics.h` library to open a graphics window and draw four basic geometric shapes:

1. A Straight Line
2. A Circle
3. A Rectangle
4. A Triangle

The program waits for a key press before closing the graphics window.

## Requirements

- C++ Compiler (MinGW-w64 / GCC)
- WinBGIm Graphics Library (`graphics.h`)
- VS Code (or any C++ IDE)

## Source File

`CGM_LabAssignment1_BasicShapes.cpp`
